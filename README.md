# CodeAlpha Task 2: Exploratory Data Analysis (EDA)

## Project overview
Explore the e-commerce product dataset created in Task 1. This notebook examines dataset structure, missing values, duplicates, price/rating summaries, categories, availability, and potential unusual values.

## Dataset
Use the real CSV generated by your Task 1 project:
`CodeAlpha_Ecommerce_Web_Scraping/outputs/ecommerce_products.csv`

Copy that file into this project's `data/ecommerce_products.csv`. The notebook also checks a few common nearby locations. Do not replace it with invented results.

Expected columns from Task 1:
`product_name`, `price_raw`, `price_value`, `rating`, `availability`, `product_url`, `category`, `scraped_at_utc`.

```text
Code-Alpha-Exploratory-Data-Analysis/
```

## Run the project
1. Install Python 3.10+ and Jupyter Notebook.
2. Install dependencies: `pip install -r requirements.txt`
3. Copy the Task 1 CSV to `data/ecommerce_products.csv`.
4. Open `notebooks/ecommerce_eda.ipynb`.
5. Run all cells from top to bottom.
6. Review the printed outputs and complete the conclusions section in the notebook.

## Deliverables
- Executed Jupyter Notebook with actual outputs
- Data quality summary and descriptive statistics
- Written conclusions based on your own run

## Important
The notebook is a reusable analysis template. Run it on the actual CSV and review the findings before claiming results. Do not automatically delete outliers; investigate them first.
